# Demo albums

Run the server from the project root with `PHOTO_DIR=./demo go run ./cmd/photo-server`.
Request all images with `GET /api/photos/next` or select an album with
`GET /api/photos/next?album=landscapes` or `?album=imagination`.

These are existing AI-generated artworks by [VulcanSphere](https://commons.wikimedia.org/wiki/User:VulcanSphere), downloaded unmodified from Wikimedia Commons. They are illustrative images, not photographs of actual events. Capture time and GPS information may be absent.

All images are dedicated under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) except `imagination/night-city.jpg`, which is © VulcanSphere, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); no changes were made.
